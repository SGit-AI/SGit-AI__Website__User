The sources

This site writes nothing of its own about how the workflows work. Every claim is drawn from a dated article or note on newsroom.sgit.ai or sgit.ai, read on 21 Oct 2026, and the rule from sgit.ai's own guidance applies: if a paragraph exists in the source and again here, they will disagree, and the source is the one that is right. Where this site adds anything, it is the arrangement, the status column, and the questions it puts on the comms page.

sgit.ai's guidance for a *.sgit.ai site

PageWhat it told this site to do
Three surfaces: which one are you building for?This is a site page, outside every vault host: indexed, linkable, readable with no key. On this surface the site is the host and must distrust the vault.
Reading a vault from a *.sgit.ai site pageDo not write the reader; copy the house code into the site rather than fetching it across origins; print read keys, never vault keys; grep the built site for key shapes as a step that can fail the build; cache immutable objects, never the ref.
Creating and writing a vault from JavaScriptOne code base for everything that writes: the vault UI library, copied into the site at a known commit, never edited. Not done here yet; T1.
Starting prompts for the regular workHow a sibling site is added to the network, and the release discipline every site follows: a version file, a gate, a tagged release.
The sgit.ai networkWhat a focused site is: one question, its own version history and repository, sourced claims, a stated status, honest edges, published before the thing exists so the commitments stay checkable.
SGit-AI__Website__Subscriptions, __TeamsThe build tooling this repository copies: chrome.py, validate.js, the generators, the deploy pipeline, and the stylesheet.

users.sgit.ai

The account is a vault, and the user holds it: a passkey opens a door, the door opens a master, the master holds the keys, and the user's browser keeps the record and the meter. No sign-in to the site, no account database, no server of ours that can read a thing. CC BY 4.0, part of the sgit.ai network.
